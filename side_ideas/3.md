# Side Idea 3

## Hierarchical Latent Belief State For A Dynamic Prediction-Market Universe

Core framing:

- we learn a compact latent belief state for the contemporaneous prediction-market universe;
- the representation is hierarchical rather than a single global vector;
- it is meant to retain enough task-relevant structure for downstream forecasting, trust, and repricing tasks.

Main object:

- a global state `g_t` that summarizes the market-wide belief climate;
- a local state `h_{m,t}` that summarizes the state of a target market `m` at time `t`.

Inputs:

- current and recent state of the target market;
- states of related markets;
- graph and coherence context;
- text and metadata;
- external signals.

Downstream use:

- terminal forecasting;
- trustworthiness / selective prediction;
- repricing prediction;
- information-uptake probes.

Why it is interesting:

- it turns the current benchmark suite into probes of one shared representation;
- it is more realistic than claiming one vector explains all of Polymarket;
- it fits naturally with changing market universes, cross-market structure, and multimodal inputs.

Careful version of the claim:

- not "one embedding captures all market knowledge";
- instead, learn compact global and local states that preserve enough task-relevant structure to generalize across downstream evaluations.

Good evaluation variants:

- frozen encoder plus simple probes;
- low-label transfer;
- unseen domain transfer;
- cold-start new-market evaluation;
- coherence-repair or belief-revision probes.

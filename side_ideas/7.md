# Side Idea 7

## Outdated-Prior Belief Update via Contextual Market and External Signals

### Core idea

- take the canonical question representation;
- exclude reframing variants of the same question;
- sample an outdated probability from approximately one week before the resolution cutoff;
- provide the model with the full contemporaneous Polymarket state and external signals (macro, crypto, and eventually GDELT news) covering the intervening week;
- task: improve the outdated estimate using the context window.

Two candidate framings: (A) the benchmark itself as the main contribution, or (B) a foundation model for Polymarket belief updating.

---

## Why the task is well-motivated

The setup creates a natural information-gain task: here is a stale probability, here is what happened in the world, now update it. Ground truth is clean (the resolved outcome, or the final pre-resolution price). The task naturally requires multimodal context processing and avoids the trivial regime where market price is already the best predictor, because the model is deliberately handicapped with an outdated snapshot. The practical analogy is a human forecaster catching up after a week away.

---

## Stream A: The benchmark as the main contribution

### Strengths

- clean single task with unambiguous ground truth;
- directly measures information gain decomposable by source (Polymarket signals vs. external signals vs. news);
- interpretable scientific findings rather than only leaderboard numbers;
- well-scoped for a D&B track submission.

### Weaknesses relative to the existing benchmark suite (01–03)

- narrower than the existing suite which covers forecasting, trust, and repricing across multiple task families;
- as a standalone paper the scientific novelty depends heavily on framing; reviewers will ask how it differs from a standard context-conditioned forecasting task with an informative prior.

### Recommended role

This task is probably strongest as benchmark 06 added to the existing suite rather than a standalone paper. It complements terminal forecasting (01) by explicitly modeling the belief-update mechanism rather than treating the market price as a static input.

---

## Stream B: Foundation model for Polymarket belief updating

### Relationship to Side Idea 3

Side Idea 3 and this idea attack the same underlying question — can we learn a compact representation of the Polymarket system useful for downstream tasks — but from different angles.

- Idea 3 approaches it architecturally: hierarchical latent state, global `g_t` plus local `h_{m,t}`, multiple pretraining objectives, multiple downstream probes.
- This idea approaches it through a specific task formulation: update a stale belief given a context window.

### Where Idea 3 is stronger for main track

- richer evaluation story: the hierarchical state is probed through forecasting, trust, repricing, information uptake, frozen-probe transfer, low-label adaptation, and unseen-domain generalization;
- cleaner scientific narrative: "learning representations of collective belief systems" is a novel object of study in ML, whereas "updating stale predictions with context" reads as more applied;
- deeper connection to representation learning literature.

### Where this idea is stronger than Idea 3

- much lower execution risk: no encoder architecture to design, no pretraining objectives to tune, tighter critical path;
- cleaner information-theoretic angle: the probability update framing lets you decompose exactly how much of the gain comes from Polymarket signals vs. external signals vs. news;
- easier to motivate to non-specialist reviewers.

### Relationship to Side Idea 4

Idea 4 (compact external-context state) is essentially the representation-learning formalization of this task. Both ask whether the external and cross-market context can be compressed into a useful representation for updating beliefs. The two ideas should be merged or treated as complementary layers of the same paper.

### Relationship to other side ideas

- Idea 1 (market-conditioned forecaster for unseen questions): conceptually related but targets zero-shot generalization to untraded questions, which is harder to evaluate rigorously. This idea has cleaner ground truth.
- Idea 5 (external shock propagation): complementary; can serve as a supporting experiment showing that the context encoder captures shock propagation as a byproduct.
- Idea 6 (masked market reconstruction): stronger as a standalone benchmark proposal because it frames the full market system as a structured prediction problem with natural pretraining objectives and foundation-model-style evaluation. This idea is narrower but more executable.

---

## Recommended path

The best ratio of scientific payoff to execution effort is a hybrid of this idea, Idea 4, and elements of Idea 3.

### Primary task

Use the outdated-prior update formulation as the main task. Clean, well-motivated, easy to evaluate.

### Method

Learn a compact context encoder (Idea 4's `z_context`) that compresses the non-local world — related markets, external signals, and eventually GDELT news — into a fixed representation. The probability update task provides the primary training signal.

### Evaluation breadth

Show that the same frozen context encoder transfers to repricing prediction, trust estimation, and cold-start markets. This provides the multi-probe depth that main-track reviewers expect.

### Track decision

- if frozen-encoder transfer across tasks and domains is meaningful: main track;
- if transfer does not materialize but the benchmark is clean and well-executed: D&B track, as part of the full benchmark suite (01–03 plus this task as 06).

### What still needs to be built

- GDELT integration for news signals;
- the outdated-snapshot sampling procedure (select snapshot approximately one week before cutoff, exclude reframing variants);
- the compact context encoder;
- everything else is already in the existing pipeline.

---

## What this idea does not replace

- the existing benchmark suite (01–03) remains the backbone;
- Idea 3's hierarchical latent state framing remains the strongest main-track narrative if execution resources allow;
- this idea is best treated as either (a) an additional benchmark task enriching the suite, or (b) a tractable entry point into the foundation-model story with lower execution risk than Idea 3 alone.

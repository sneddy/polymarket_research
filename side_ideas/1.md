# Side Idea 1

## Market-Conditioned Probabilistic Forecaster For Unseen Or Untraded Questions

Core idea:

- build a system that can output probabilities for questions that were not directly seen during training or are not currently traded as contracts;
- condition the forecast on the contemporaneous state of Polymarket rather than treating the question in isolation.

Inputs:

- text of a new question;
- current state of relevant markets;
- graph and coherence context from related contracts;
- external signals.

Why it is interesting:

- it turns Polymarket into a structured probabilistic memory rather than a set of isolated price series;
- it tests whether market-grounded inference generalizes beyond seen contracts;
- it is stronger than pure question-only forecasting because the prediction is conditioned on a live market system.

More realistic version of the claim:

- not "answer arbitrary questions about the world";
- instead, estimate probabilities for unseen, newly listed, or logically derived questions by grounding on related traded contracts.

Good evaluation variants:

- unseen traded contracts;
- cold-start newly listed contracts;
- derived but untraded questions from existing market families.
